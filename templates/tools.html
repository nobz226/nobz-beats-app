Audio Tools API (by Nobz)

Use the forms below to analyze, convert or separate audio. Files are sent to the server and the results are shown or downloaded.

Analyzer

Detect tempo (BPM) and key.

Converter

Convert to MP3 / WAV / FLAC.

Stem Separator

Run Demucs to extract stems (zip download).

Stem Transcription

Upload a single stem and receive a simple note transcription.

System status

Checking system (Demucs, FFmpeg, Torch cache)...

Note: Processing may take several seconds (or minutes for stem separation). Demucs/FFmpeg must be installed on the server.
