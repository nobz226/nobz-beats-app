Audio Tools API (by Nobz)

This repository exposes three audio tools as a minimal REST API: Analyzer, Converter, and Stem Separator. No UI forms here—use curl or your own client to upload audio files.

GET/audio/test

Simple health/test endpoint.

curl http://localhost:5002/audio/test
POST/audio/analyze

Analyze an uploaded audio file (detect tempo & key). multipart form field: file

curl -F "file=@/path/to/song.mp3" http://localhost:5002/audio/analyze
POST/audio/convert

Convert an uploaded file to a format. multipart form field: file, form field: format (mp3|wav|flac)

curl -F "file=@/path/to/song.wav" -F "format=mp3" http://localhost:5002/audio/convert --output converted.mp3
POST/audio/separate

Run stem separation (Demucs). multipart form field: file. Optional form field: model (defaults to htdemucs).

curl -F "file=@/path/to/song.mp3" -F "model=htdemucs" http://localhost:5002/audio/separate --output stems.zip

Notes: Demucs and FFmpeg must be installed on the host. See requirements.txt and README for details.
